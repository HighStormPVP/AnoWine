# The components of Ano's runtime and their licenses (Plan 3c-5). build-engine.sh's
# write_licenses ships each component's license files in
# Libraries/Ano/share/ano/licenses/<component>/<path> and lists every component in
# Libraries/Ano/share/ano/NOTICES; check-licenses.sh fails a runtime with a file no
# component covers, a missing or empty license text, or a component NOTICES lacks.
#
# One line per component, tab-separated:
#   component  version  spdx  source  license-files  covers  modified
# source:
#   winecx            the engine's source (WINECX_URL at WINECX_COMMIT, read before the rename)
#   recipe            upstream's recipe files (RECIPE_BASE); they publish no license
#   nix:<attribute>   x86_64-darwin <attribute> of nixpkgs at NIXPKGS_REV; its version and
#                     meta.license must equal the line's, and the files come from its .src
#   url:<URL>         a URL pinned in build-engine.sh: a tarball (with its _SHA) or a git
#                     repository (with its _COMMIT)
#   payload:<folder>  a folder of build-payloads.sh's output (ANO_PAYLOADS)
# license-files: comma-separated paths inside that source, never edited; - only for an
#   spdx of NOASSERTION (the source publishes no license).
# covers: comma-separated globs relative to Libraries/ (* inside one folder, ** across
#   folders, **/ also none), or - for a component built into another's files. The first
#   matching line owns a file, so payloads under Ano/share/ano come before the engine.
#   Third-party libraries in Ano/lib are listed one family per component: a library
#   added later with no line here fails the check.
# modified: no, or what Ano changed (Apache-2.0 4(b), zlib's "plainly marked").
#
# The nix lines: the libraries bundle_libraries copies from the closure of
# NIX_X86_PACKAGES (Ano Engine run 44912708138: 432 libraries, 231 GStreamer plugins,
# whose copies in Ano/lib the ** globs cover too).
